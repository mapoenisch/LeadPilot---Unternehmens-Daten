# LeadPilot – Unternehmensdaten

Dieses Repository enthält alle Unterlagen des fiktiven Unternehmens **LeadPilot GmbH** im Rahmen eines Digital Sales Manager-Projekts.

## 📋 Über LeadPilot

LeadPilot ist ein KI-gestütztes CRM-System für den B2B-Mittelstand mit Fokus auf:

- Automatisierte Lead-Scoring und -Qualifizierung
- Messe- und Event-Management (LeadPilot Expo)
- Intelligente Nachverfolgung und Task-Management
- Personalisierte Sales-Automatisierung

## 🚀 Verwendung

### Designsystem nutzen
1. `LeadPilot-Designsystem/LeadPilot-Grotesk.zip` entpacken
2. Schriften installieren (Windows: Rechtsklick → Installieren; macOS: Doppelklick → Installieren)
3. Designsystem-Richtlinien in `guidelines/` beachten

### Marketingmaterial verwenden
- Expo-Bilder liegen im Ordner `LeadPilot-Expo-Marketingpaket/`
- Landingpages können direkt im Browser geöffnet werden
- Präsentationen als Vorlage für Sales-Pitches nutzen

### Unternehmensdaten prüfen
- Dashboard öffnen: `LeadPilot - Unternehmensdaten-Projekt Kontext/LeadPilot_Unternehmens_Dashboard.html`
- Finanzdaten in den Excel-Dateien
- Strategische Dokumente im Projekt-Kontext-Ordner
