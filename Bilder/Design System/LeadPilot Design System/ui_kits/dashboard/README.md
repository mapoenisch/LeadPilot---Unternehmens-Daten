# LeadPilot Dashboard UI Kit

Interactive recreation of the LeadPilot app dashboard: a persistent sidebar (Overview, Leads, Sequences, Settings) and four click-through views.

- **Overview** — stat cards (one featured with a cyan glow) + a recent-leads table.
- **Leads** — filterable tabs, a leads table with status badges, and an "Add lead" modal.
- **Sequences** — a sample outreach sequence with numbered steps.
- **Settings** — a simple account form.

Composes the design system's `NavItem`, `Card`, `SectionHeader`, `Table`, `Tabs`, `Modal`, `Input`, `Badge`, `Button`, `Icon`, `Divider`.

Source: no app codebase or Figma was provided — built from the LeadPilot UI-System/Color-System markdown specs and the "Simple dashboard" use case they call out.
