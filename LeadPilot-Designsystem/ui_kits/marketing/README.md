# LeadPilot Marketing Site UI Kit

A recreation of the LeadPilot marketing landing page: header, hero, three-card feature grid (middle card featured with a cyan glow), CTA band, footer.

Built from `ui_kits/marketing/index.html` composing `MarketingHeader.jsx`, `Hero.jsx`, `FeatureGrid.jsx`, `CTASection.jsx` with the design system's `Button`, `Badge`, `Card`, `Icon` components.

Source: no marketing site codebase or Figma was provided — built directly from the LeadPilot brand markdown files (UI-System, Color-System, Mini-Design) and the "one-screen example" they describe (headline, subline, primary CTA, accent badge, 2–3 feature cards).
